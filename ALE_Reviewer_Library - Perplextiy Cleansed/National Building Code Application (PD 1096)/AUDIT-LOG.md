## ERRORS CORRECTED

### Error 1 — File 7: Balcony Clearance (Already Corrected in Original)
- **Where:** File 7 (Setbacks, Easements, and Projections)
- **Issue:** Circulating review materials cite balcony clearance as 2.40m
- **Correction:** Balcony clearance = **3.00m** per PD 1096, Sec. 1003(b). The 2.40m value applies to awnings (Sec. 1006) and doors/windows (Sec. 1007).
- **Severity:** MAJOR — directly tested on ALE
- **Status:** Original already corrected this; preserved in improved version

### Error 2 — File 7: Underground Projections Conflation (Already Corrected in Original)
- **Where:** File 7 (Setbacks, Easements, and Projections)
- **Issue:** Many reviewers present Sec. 1002(b) and 1002(c) as a single "depth progression table"
- **Correction:** These are TWO separate provisions: (b) footings along national roads at ≥2.40m depth / max 300mm projection; (c) foundations into public sidewalks / max 500mm width / top ≥600mm below grade. Different building elements. Different locations. Different rules.
- **Severity:** MAJOR — exam tests the distinction
- **Status:** Original already corrected this; preserved in improved version

### Error 3 — File 8: Exit Separation Rule (Already Corrected in Original)
- **Where:** File 8 (Egress, Corridors & Occupant Loads)
- **Issue:** Commonly circulated reviewers state "exits must be separated by 1/2 the diagonal dimension"
- **Correction:** PD 1096 Sec. 1207(2)(c) specifies **1/5 of the perimeter**, NOT 1/2 diagonal. The 1/2-diagonal rule is from the International Building Code (IBC), which does NOT govern the ALE.
- **Severity:** CRITICAL — wrong formula produces wrong answers
- **Status:** Original already corrected this; preserved in improved version

### Error 4 — File 8: Fabricated Corridor Widths (Already Corrected in Original)
- **Where:** File 8 (Egress, Corridors & Occupant Loads)
- **Issue:** Many reviewers claim "Educational corridors = 1.80m, Institutional corridors = 2.40m"
- **Correction:** Sec. 1207(4)(a) states ONE minimum: **1.10 meters** for ALL occupancies. No occupancy-specific corridor widths exist in PD 1096 Section 1207. The wider values may originate from RA 9514 IRR or BP 344 but have NO basis in PD 1096.
- **Severity:** CRITICAL — presenting fabricated code provisions destroys exam credibility
- **Status:** Original already corrected this; preserved in improved version

### Error 5 — File 3: Emoji Contamination & Formatting

## RETENTION STRATEGY

### Tactic 1: Error-Based Learning (Strongest Effect)
Every major correction is presented in a WRONG → RIGHT format. The student physically reads the wrong answer, sees it crossed out / flagged, and reads the correct one. Research shows this correction-contrast encoding creates stronger memory traces than seeing the correct answer alone. Files 7 and 8 include explicit "Error-Correction Rituals" where students write wrong answers on paper, cross them out, and write corrections.

### Tactic 2: Pattern Interrupts & Von Restorff Isolation
Bold TRAP ALERT sections, comparison tables, and visual diagrams break the monotony of dense legal text. Per the Von Restorff Effect, isolated or distinctive items are remembered better than homogeneous content. Each exam trap is visually isolated with its own header and Wrong/Right contrast table.

### Tactic 3: Active Recall with Spaced Repetition
Every module ends with:
1. A 60-Second Blitz Quiz (rapid-fire recall under time pressure)
2. Full Active Recall questions with hidden answers (details/summary tags)
3. A spaced repetition schedule (Day 1 → Day 3 → Day 5 → Day 8 → Day 14)
The student cannot passively re-read — they must retrieve the information, which is the single most effective study technique per cognitive science research.
