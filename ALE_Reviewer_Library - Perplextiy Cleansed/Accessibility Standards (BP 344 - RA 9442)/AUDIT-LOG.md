## CROSS-FILE PATTERN ANALYSIS

### Pattern 1: Pervasive Ramp Width vs. Corridor Width Confusion

This is the single most recurring error across the review series. Files 4, 5, 6, and 7 all cite **1200mm** as the accessible route or corridor width when the correct value for internal building corridors is **1500mm** (BP 344 2024 IRR, Sec C.5.1). The 1200mm figure is correct only for ramps (Sec A.1.2.a).

**Affected files:** 4, 5, 6, 7  
**Severity:** CRITICAL — wrong number memorized with high confidence  
**Correction:** Always distinguish: Ramp = 1200mm; Corridor = 1500mm; Passing space = 1800mm x 2000mm

### Pattern 2: Grab Bar Height Misattribution (File 1)

File 1 cites 800mm AFF as the toilet grab bar height. The BP 344 2024 IRR does not use 800mm AFF for grab bars; the height is referenced as 300mm above the toilet seat (Sec 6.3.b). The 800mm figure appears in the file as the lavatory counter height (Sec 6.9), and the confusion between these two fixtures is predictable.

**Affected files:** 1  
**Severity:** CRITICAL — produces wrong exam answers

### Pattern 3: Duplicate Content Replacing Missing Content (File 4)

File 4 was supposed to cover Tactile Warning Surfaces, Braille Signage, and Visual Alarms — a distinct exam topic. Instead, it contains a near-verbatim copy of File 5's content (BP 344 vs. PD 1096 comparison). This leaves a complete gap in tactile/signage/alarm coverage across the entire review series.

**Affected files:** 4  
**Severity:** CRITICAL — entire exam topic absent from the series

### Pattern 4: RA 10754 Tax Deduction Percentage Error (File 7)

File 7 consistently cites 50% as the deduction for building modifications when the current law (RA 10754 Sec 4) sets this at 25%. Both the exam trap section and the peso computation example use the wrong percentage, making this error self-reinforcing within the file.

**Affected files:** 7  
**Severity:** CRITICAL — professional practice advice using wrong figures

## RETENTION STRATEGY — Psychological Tactics Embedded in the Review Series

The following pedagogical techniques are embedded throughout the 7-file series:

### Tactic 1: Pattern Interrupts (Von Restorff Effect)

**Implementation:** Bold tables, TRAP ALERT boxes, and "WRONG → CORRECT" call-out blocks break the visual monotony of continuous prose. The human brain is wired to notice contrast; anything visually distinct from its surroundings receives elevated attention and encoding priority.

**Evidence in files:** Every file uses tables with alternating row content, "❌ WRONG / ✅ CORRECT" paired structures, and bold headers to force visual re-engagement after every 3-4 paragraphs. These pattern interrupts prevent the "passive reading" that kills retention.

**Optimization note:** The TRAP ALERT boxes in File 7 (corrected version) front-load the wrong answer before revealing the correct one, leveraging the "hypercorrection effect" — errors caught in the act of being made are 3x more memorable than facts stated without the trap.

### Tactic 2: Error-Based Learning (Hypercorrection Effect + Error Management Training)

**Implementation:** All files present wrong answers explicitly, labeled as such, before revealing the correct value. This activates the hypercorrection effect: when a learner has confidently held a wrong belief and then encounters the correction with high emotional salience, the correct version is encoded more deeply than if the wrong version had never been encountered.

**Evidence in files:** The "Board Exam Traps" sections in every file provide wrong answers in exam-question format, creating a retrieval failure that triggers emotional correction. The "TRAP ALERT" boxes in the corrected File 7 use an even more aggressive version: showing the exact wrong text from a discredited source before replacing it with the verified standard. This creates a "before/after" memory hook tied to the emotional recognition of having been misled.

### Tactic 3: Active Recall (The Testing Effect / Retrieval Practice)

**Implementation:** Every file ends with a "Active Recall Battery" section requiring the learner to cover answers and retrieve information before checking. Research (Roediger & Butler, 2011) shows that retrieval practice produces 50-100% better long-term retention than re-reading the same material.

**Evidence in files:** Questions are sequenced from definitional ("What is the minimum width?") to applied ("Calculate the footprint of a ramp system") to synthesis ("Which law provides this benefit?"). The escalating difficulty mirrors Bloom's taxonomy and prevents shallow "recognition" recall — forcing deeper "recall" encoding. The "Protégé Effect" challenge at the end of each file adds a teaching retrieval layer (explain to a peer), which research shows activates metacognitive monitoring and identifies gaps the learner didn't know existed.
