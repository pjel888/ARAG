## The Real-World Scenario (The Hook)

You're designing a Quezon City public school-hospital-library complex. **30 kids suffocate in a cramped classroom (under 3m³ air/person).** A wheelchair user can't access the library. Nurses trip in narrow hospital corridors. **Master Group D + air space = ALE gold + zero violations.**

**Quick Win**: Group D = "Institutional lives." 3m³/person = exam magic number.

## Core Concepts (Mnemonic Lock-In)

**GAB Framework** (Mnemonic: **G**roup D, **A**ir Space, **B**arrier-Free):

- **Group D Occupancies**: Schools, hospitals, libraries, jails (PD 1096 Rule V).
- **Air Space**: **3.0 m³/person** minimum (school rooms only – exam trap!).
- **Barrier-Free**: BP 344 ramps/elevators in listed institutional spaces.

| Institution   | Air Space          | Barrier-Free         | PD 1096 Rule        |
| ------------- | ------------------ | -------------------- | ------------------- |
| **Schools**   | 3.0 m³/person      | Auditoriums/gymnasia | Rule V, Sec. 603    |
| **Hospitals** | General occ. rules | Mental hospitals     | Rule V, Sec. 603    |
| **Libraries** | N/A                | **MANDATORY**        | Rule VIII, Sec. 804 |

_Fact-Check_: PD 1096 (2017) Rule V, Sec. 603.D.2.1: "School rooms shall have 3.00 cubic meters per person."

## Step-by-Step Computation (Exam Gold!)

**Classroom Capacity Example**:

1. Room: 7m L × 9m W × 3.2m H = **201.6 m³**
2. Per person: 3.0 m³ → **67 students maximum**
3. Check exits: 67 × 0.55m/person = **37m egress width total**

**Barrier-Free Check**: Library? → **YES, ramps required.**

4. **Trap #4**: Capacity calc forgets **height × length × width**.
